# Benchmarks and evidence layer

This directory hosts the repository's reproducible evidence layer. The goal is not to turn this repository into a production platform or framework; it is to make the strongest engineering claims testable under a controlled local methodology.

## Scope

The benchmark suite is intentionally narrow and follows the repository's core themes:

- response-delivery bottlenecks
- context lifecycle management
- authority / intent conformance

## Benchmark command map

```bash
# response delivery
python benchmarks/response-delivery/benchmark.py

# context lifecycle
python benchmarks/context-lifecycle/benchmark.py

# authority conformance
python -m pytest benchmarks/authority-conformance/test_authority_conformance.py -q
```

## Evidence posture

All benchmark numbers are generated by code in this repository and are intended to be read as local, controlled experiments, not as production deployment measurements. The repository remains explicit that these results are not proof of a deployed system's production performance.

Each benchmark directory contains:

- a short README
- a runnable script
- methodology and interpretation notes
- clear caveats about what is and is not measured
